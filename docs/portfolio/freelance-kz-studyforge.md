# StudyForge 2.1 — материал для портфолио Freelance.kz

### Project title

StudyForge — обработка PDF и AI-интеграция на Python и FastAPI

### Short description

Локальное веб-приложение на Python и FastAPI: обработка PDF и OCR на казахском, русском и английском языках, создание конспектов, карточек и интерактивных тестов. Интеграция Gemini API, история материалов, учёт токенов и оценка стоимости запросов.

### Full description

StudyForge помогает превращать учебные PDF в материалы для повторения: конспекты, карточки и тесты. Пользователь загружает документ, просматривает извлечённый текст, выбирает страницы и формат результата. Материалы сохраняются в локальной истории и доступны без повторной генерации для того же диапазона, формата, провайдера и модели.

Backend реализован на Python и FastAPI, интерфейс — на HTML, CSS и JavaScript без отдельной сборки frontend. Текстовый слой PDF извлекается через pypdf. Для страниц со слабым текстовым слоем подключается локальное OCR: PDFium подготавливает изображение, а Tesseract распознаёт казахский, русский и английский языки. Документы, распознанный текст и материалы хранятся в SQLite и локальных файлах.

Для AI-генерации реализован серверный адаптер Gemini API со структурированным ответом. Результат проверяется перед сохранением; для карточек и тестов проверяются ссылки на исходные страницы. В интерфейсе есть переворачиваемые карточки, перемешивание вариантов ответов, подсчёт результата теста и разбор ответов. Отдельный адаптер поддерживает OpenAI-совместимый API.

Инженерная часть включает проверку типа и размера загрузки, обработку повреждённых PDF, безопасные имена файлов, разделение анонимных библиотек по cookie, фоновые задачи с состоянием в SQLite и восстановление после перезапуска. Для OCR заданы таймауты и ограничения параллельности. Для Gemini предусмотрены учёт токенов, дневной журнал попыток и ограничение оценочного бюджета. Ключи API остаются на сервере, а вывод документа и AI-ответов вставляется в интерфейс как текст.

При подготовке релиза прошли 51 Python-тест, 5 JavaScript-тестов и сквозная проверка Chromium. Проверялись реальные OCR-модели трёх языков, генерация через сетевые заглушки, история, удаление документов, изоляция данных, обработка ошибок и защита от внедрения HTML. Платные обращения к AI-провайдерам при релизной проверке не выполнялись.

Проект демонстрирует разработку приложения для обработки документов и интеграции внешнего API. Он предназначен для локального запуска и технической демонстрации. Для публичного многопользовательского сервиса потребуются отдельная авторизация, ограничения ресурсов и усиленная изоляция обработки PDF. При включённом AI-режиме фрагменты документа передаются внешнему провайдеру; показанная стоимость запросов является оценкой.

### Technologies

Python 3.12, FastAPI, Uvicorn, Pydantic, SQLite, HTML, CSS, JavaScript, Google Gen AI SDK / Gemini API, HTTPX, pypdf, pypdfium2 / PDFium, tesserocr / Tesseract, Pillow, pytest, Node.js test runner, Playwright / Chromium.

### My contribution

В рамках проекта реализованы backend API, интерфейс работы с документами и учебными материалами, PDF/OCR-конвейер, серверные AI-адаптеры, хранение истории и учёт использования. Выполнены проверка безопасности, регрессионные тесты и подготовка воспроизводимой локальной демонстрации.

При аудите и подготовке релиза использовались AI-инструменты разработки. Изменения проверялись по коду и автоматическими тестами; описание не предполагает, что каждая строка была написана вручную.

### Optional English version

StudyForge is a local Python/FastAPI study workspace for PDF processing, Kazakh/Russian/English OCR, summaries, flashcards, and interactive quizzes. It combines a vanilla JavaScript interface, SQLite history, server-side Gemini integration, structured-output validation, token accounting, and configurable request-budget controls. Release verification covers 51 Python tests, 5 JavaScript tests, and a Chromium workflow. Screenshots use a synthetic PDF in local Mock Mode. A public multi-user deployment would require additional authentication and resource isolation.
